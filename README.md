# Workflow Builder (web)

Point-and-click GitHub workflow composer for the
[`OseMine/workflows`](https://github.com/OseMine/workflows) action library.

- Browse all 35+ actions live.
- Add any action as a step, configure its inputs in a friendly form.
- Pick which version of the actions to pin: `@v1` (stable), `@latest`
  (rolling), or `@main` (branch head).
- Get a ready-to-commit workflow `.yml` with `actions/checkout`, triggers,
  permissions, and your chosen steps — copy or download it.
- One-click presets: CI, Build, Release, Security.
- Monochrome (black & white) Apple-inspired look with automatic **dark/light
  mode** — follows your system, or toggle it manually via the header button.

## Autoupdating

The action catalog is **not** part of this site. On every load the app fetches
`catalog.json` from the main branch of `OseMine/workflows`
(`https://raw.githubusercontent.com/OseMine/workflows/main/catalog.json`),
so the moment an action/input is added or changed in the library, it shows up
here automatically — no redeploy needed.

`catalog.json` is regenerated by `.github/workflows/library-ci.yml` on every
push (and manually via `scripts/build-catalog.py`).

## Deploying (GitHub Pages)

This branch is a standalone static site:

1. Repo → **Settings → Pages**.
2. **Source: Deploy from a branch**.
3. Branch: `web`, folder: `/ (root)`.
4. Save — the site appears at `https://osemine.github.io/workflows/`.

No build step, no dependencies, no frameworks — just `index.html`,
`style.css`, `app.js`, `.nojekyll`.
